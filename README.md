# Login Motion Lab — Week 06

Fancy sign-in / sign-up demo (Vue 3 + Vite, CSS motion, localStorage).

- `index.html` — готовая страница (всё внутри одного файла). Открывается двойным кликом и работает на GitHub Pages.
- `source/` — исходный код проекта (Vue + Vite). Запуск: `cd source && npm install && npm run dev`.

UI practice only. Passwords are not saved or verified.
